
# Infrastructure

This folder contains everything needed to provision and deploy the RealEstate stack using Terraform (Hetzner Cloud) + Ansible (Docker Compose deploy).  
Goal: reproducible infra, predictable deploys, and a clean “one-command” workflow via `Makefile`.

## Structure

```text
infrastructure/
  terraform/                 # Terraform code (Hetzner Cloud)
    main.tf
    variables.tf
    outputs.tf
    versions.tf
    load_balancer.tf
    terraform.prod.blue.tfvars
    terraform.prod.green.tfvars

  ansible/                   # Ansible deploy (Docker on servers)
    playbook.yml
    roles/
      app/
        tasks/main.yml
        defaults/            # role defaults (variables)
    group_vars/
      realestate_prod/
        vault.yml            # encrypted secrets (Ansible Vault)
      realestate_prod_blue.yml
      realestate_prod_green.yml

  README.md                  # (this file)
  ```
## Prerequisites
Install locally:

- Terraform >= 1.5
- Ansible
- SSH client
- ssh-keyscan / ssh-keygen
- Access token for Hetzner Cloud (HCLOUD_TOKEN)

## Environments & Workspaces
We use the convention:

- `ENV` — environment (default: `prod`)
- `STACK` — blue/green slot (default: `blue`)

Terraform workspace name:

- `TF_WORKSPACE = $(ENV)-$(STACK)`
  Examples: `prod-blue`, `prod-green`

Terraform variables file per stack:

- `terraform.prod.blue.tfvars`
- `terraform.prod.green.tfvars`

## Secrets
### Terraform
Provide Hetzner token via environment variable:
```bash
cd infrastructure/terraform
printf '%s' 'hcloud_token = "token"' > terraform.tfvars
chmod 600 vault-password
```

### Ansible Vault
Secrets must not be committed in plaintext. Use Ansible Vault:

- infrastructure/ansible/group_vars/realestate_prod/vault.yml — encrypted
- infrastructure/ansible/vault-password

Example:
```bash
cd infrastructure/ansible
printf '%s' 'super_secret_password' > vault-password
chmod 600 vault-password
```
## Generated Files
Inventory files are generated by Terraform outputs and used by Ansible:
infrastructure/ansible/inventory.*.ini
infrastructure/ansible/inventory.prod.blue.ini
infrastructure/ansible/inventory.prod.green.ini
